# Yusuf Aslam · Portfolio

My personal portfolio site, live at **https://yusuf011-4023.github.io/**

Projects are loaded automatically from my public GitHub repos, so new work appears on the site without editing the code.

## Editing

Everything lives in `index.html`:

- **Colours:** the `:root { ... }` block at the top of the `<style>` section
- **Name, subtitle and About Me text:** in the HTML, marked with `EDIT` comments
- **Username, LinkedIn, email, pinned and hidden repos:** the `CONFIG` object at the top of the `<script>` section

To preview locally, open `index.html` in a browser. Pushing to `main` updates the live site within a minute or two.
